# Simple Mobile Robot Autonomy

This project extends the **simple-mobile-robot** repository by adding autonomous mapping, localization, and navigation capabilities using ROS 2 and Gazebo.

## Project Roadmap

- Mobile Robot Simulation
- Sensor Integration
- TF Tree
- SLAM
- Mapping
- Localization (AMCL)
- Navigation2
- Autonomous Navigation
- Depth Camera Processing
- Frontier Exploration
- Simulation Improvements
